**LifeOS UI/UX Design Specification**
=====================================

**1. Design Philosophy and Principles**
--------------------------------------

* **User-centered design**: Design decisions are based on user needs, behaviors, and motivations.
* **Simplicity and clarity**: The design should be intuitive, easy to use, and free of clutter.
* **Consistency**: Establish a consistent visual language and interaction patterns throughout the app.
* **Feedback and guidance**: Provide timely and relevant feedback to help users understand the app's behavior and make informed decisions.

**2. Color System**
------------------

* **Primary color**: `#3498db` (a calming blue-green hue)
* **Secondary color**: `#f1c40f` (a vibrant orange-yellow hue)
* **Background color**: `#1A1A2E` (a dark, neutral gray)
* **Text color**: `#FFFFFF` (white)
* **Accent color**: `#2ecc71` (a bright, energetic green)

**3. Typography System**
----------------------

* **Font family**: Open Sans
* **Font sizes**:
	+ **Header**: 24px
	+ **Subheader**: 18px
	+ **Body**: 16px
* **Font weights**:
	+ **Bold**: 700
	+ **Regular**: 400
	+ **Light**: 300

**4. Spacing and Layout System**
------------------------------

* **Grid system**: A 12-column grid with a 16px gutter
* **Margin and padding**: Use a consistent 16px margin and padding throughout the app
* **Line height**: 1.5x the font size

**5. Component Library**
-----------------------

* **Buttons**:
	+ **Primary button**: `#3498db` background, white text, 16px font size
	+ **Secondary button**: `#f1c40f` background, white text, 16px font size
* **Inputs**:
	+ **Text input**: 16px font size, 16px padding, 1px border radius
	+ **Number input**: 16px font size, 16px padding, 1px border radius
* **Cards**:
	+ **Header**: 24px font size, 16px padding
	+ **Body**: 16px font size, 16px padding

**10. Animation and Interaction Patterns**
-----------------------------------------

* **Loading animation**: Use a loading animation to indicate when data is being loaded
* **Success animation**: Use a success animation to indicate when a task is completed successfully
* **Error animation**: Use an error animation to indicate when an error occurs
* **Tap animation**: Use a tap animation to indicate when a button is tapped
* **Swipe animation**: Use a swipe animation to indicate when a screen is swiped

**11. Accessibility Requirements**
---------------------------------

* **Color contrast**: Ensure a minimum color contrast ratio of 4.5:1 for normal text and 3:1 for large text
* **Font size**: Ensure a minimum font size of 16px for body text and 24px for header text
* **Screen reader support**: Ensure support for screen readers and provide alternative text for images
* **Closed captions**: Provide closed captions for video and audio content
