**LifeSphere UI/UX Design Specification**
=====================================

**1. Design Philosophy and Principles**
------------------------------------

* **User-centered design**: The app's design will prioritize the user's needs, goals, and behaviors.
* **Simple and intuitive**: The app's interface will be simple, intuitive, and easy to use.
* **Consistent and cohesive**: The app's design will be consistent and cohesive throughout.
* **Accessible and inclusive**: The app's design will be accessible and inclusive for all users.

**2. Color System**
-----------------

* **Primary color**: #1A1A2E (dark blue)
* **Secondary color**: #34A8FF (light blue)
* **Accent color**: #FFC107 (orange)
* **Background color**: #F7F7F7 (light gray)
* **Text color**: #333333 (dark gray)

**3. Typography System**
----------------------

* **Font family**: Open Sans
* **Font sizes**:
	+ **Header**: 24px
	+ **Title**: 18px
	+ **Body**: 16px
* **Font weights**:
	+ **Bold**: 700
	+ **Regular**: 400
	+ **Light**: 300

**4. Spacing and Layout System**
-----------------------------

* **Grid system**: 12-column grid
* **Margin and padding**: 16px (default), 24px (large), 8px (small)
* **Line height**: 24px (default), 30px (large), 18px (small)

**5. Component Library**
----------------------

* **Button**:
	+ **Primary button**: #1A1A2E (background), #FFFFFF (text)
	+ **Secondary button**: #F7F7F7 (background), #333333 (text)
* **Input field**:
	+ **Text input**: #F7F7F7 (background), #333333 (text)
	+ **Number input**: #F7F7F7 (background), #333333 (text)
* **Card**:
	+ **Background**: #F7F7F7
	+ **Text**: #333333
* **Chart**:
	+ **Background**: #F7F7F7
	+ **Text**: #333333
	+ **Line color**: #1A1A2E

----------------------

* **Onboarding flow**: User signs up, sets up account, and starts tracking data
* **Dashboard flow**: User views dashboard, navigates to different sections
* **Tracking flow**: User tracks data (health, workout, food, sleep, tasks, books, finance)
* **Reward flow**: User earns rewards, views reward metrics

**9. Navigation Structure**
-------------------------

* **Tab bar**: Dashboard, Health Tracking, Workout Tracking, Food and Nutrition, Sleep and Recovery, Tasks, Goals, and Habits, Books and Knowledge, Finance, Reward / Solo Leveling System, Settings

**10. Animation and Interaction Patterns**
--------------------------------------

* **Loading animation**: Spinner animation
* **Button interaction**: Button hover, button click
* **Form interaction**: Form input focus, form input blur
* **Chart interaction**: Chart hover, chart click

**11. Accessibility Requirements**
------------------------------

* **Color contrast**: Minimum 4.5:1 contrast ratio
* **Font size**: Minimum 16px font size
* **Screen reader support**: Support for screen readers
* **Keyboard navigation**: Support for keyboard navigation

**12. Dark Theme Design Tokens**
------------------------------

* **Primary color**: #1A1A2E (dark blue)
* **Secondary color**: #34A8FF (light blue)
* **Accent color**: #FFC107 (orange)

* **Text color**: #FFFFFF (white)

Note: The design tokens are used to define the visual design of the app, including colors, typography, and spacing. The dark theme design tokens are used to define the visual design of the app in dark mode.
